# Next.js Developer Portfolio Template

A modern, fast and fully customizable **portfolio template** for developers, built with **Next.js 14 (App Router)**, **Tailwind CSS**, **shadcn/ui**, **Framer Motion**, **GSAP** and more.

Designed to showcase your projects, skills, experience and personality with a clean, responsive design and smooth animations.

Perfect for **frontend developers**, **full-stack developers**, **creative developers** or anyone who wants a fast, beautiful portfolio.

## ✨ Key Features

- ⚡️ **Next.js 14** App Router + Server Components
- 🎨 **Tailwind CSS 3** + **shadcn/ui** components
- 🌗 Dark / Light mode with `next-themes`
- 🔥 Smooth animations with **Framer Motion** and **GSAP**
- 📧 Contact form with validation (**React Hook Form** + **Zod**) and email sending via **Resend**
- 🌍 Ready for multilingual support with **i18next**
- 🎨 Modern, clean design with micro-interactions and transitions

## Technologies Used

| Category                  | Main Technologies                                      |
|---------------------------|--------------------------------------------------------|

## 🚀 Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/fabrizio-ferrentino/nextjs-portfolio-developer.git

# 2. Go to the project directory
cd nextjs-portfolio-developer

# 3. Install dependencies (recommended: yarn)
npm install

# 4. Create environment file
cp .env.example .env

# 5. Start the development server
npm run dev
```
Open http://localhost:3000 in your browser.

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file
`RESEND_API_KEY`
